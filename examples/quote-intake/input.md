# Quote Intake — Synthetic Input

## Data classification

Synthetic Data。此案例為產品格式測試，不含真實客戶、公司、聯絡方式、訂單或報價資料。

## 客戶輸入

> 數量約 3000、尺寸 5×5×12cm、保養品彩盒、霧膜、局部 UV、希望九月底交貨。

## 工具目標

建立一個需求整理工具，將模糊輸入轉成固定欄位，並清楚標示缺少與不確定資訊。

## 必須保留的語意

- 數量是「約 3000」，不是精確承諾的 3000。
- 局部 UV 的位置未知，不能猜成 LOGO 或任何其他位置。
- 紙質沒有提供，必須標示缺少。
- 「九月底」是希望交貨時間；年份與是否可達成都未知。

## 明確排除

- 不自動報價。
- 不寫入 ERP。
- 不寄送電子郵件。
- 不承諾交期。
